# 나만의 인공지능 만들기

중학생 대상 3시간 특강 「나만의 인공지능 만들기」 실습 사이트입니다.

- **https://lunarjiwon.github.io/ai-class/**

| 파일 | 내용 |
| --- | --- |
| `index.html` | 첫 화면 |
| `chat.html` | 나만의 AI 채팅. 학생 노트북의 Ollama(EXAONE 3.5 2.4B)에 연결해 대화하고, 코드를 고쳐 나만의 AI를 만들어요 |
| `lab.html` | AI 개념 실험실 (AI란 / 학습 원리 / 학습 방법 3가지 / 텍스트 → 벡터) |
| `설치_도우미.bat` | 실습 PC 설치 도우미 (Ollama 설치, 모델 받기, `OLLAMA_ORIGINS` 설정) |

## 실습 PC 준비

1. `설치_도우미.bat`을 실습 PC에서 더블클릭
2. `chat.html`을 열어 오른쪽 위에 **AI 연결됨 ✓**이 보이는지 확인
3. 크롬이 "로컬 네트워크의 기기에 액세스" 허용을 물으면 **허용** → 화면의 **다시 연결**

AI는 인터넷이 아니라 학생 노트북 안(Ollama)에서 돌아가서, 질문 내용이 밖으로 나가지 않아요.
